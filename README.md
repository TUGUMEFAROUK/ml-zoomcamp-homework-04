Machine Learning Zoomcamp 2026 — Homework 4

Lead Scoring Classification

This project explores a lead-scoring classification problem using the 2026 lead-scoring dataset from DataTalksClub's Machine Learning Zoomcamp.

The objective is to predict whether a potential customer converts using logistic regression and to evaluate model performance using several classification metrics.

 Key Concepts Covered
- Data preparation and missing-value handling
- Feature importance using ROC AUC
- Categorical feature encoding with `DictVectorizer`
- Logistic regression classification
- Precision and recall analysis across classification thresholds
- F1 score optimization
- 5-fold cross-validation
- Hyperparameter tuning using regularization parameter `C`

 Technologies
- Python
- Pandas and NumPy
- Scikit-Learn
- Matplotlib
- Jupyter Notebook

 Dataset
[2026 Lead-Scoring Dataset](https://raw.githubusercontent.com/DataTalksClub/machine-learning-zoomcamp/main/cohorts/2026/data/course_lead_scoring_2026.csv)
